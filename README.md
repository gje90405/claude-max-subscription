## 用量限制：5 小时加每周，两套额度一起算

先泼一盆冷水：Max 20x 不等于无限量。官方的额度规则有两层。

第一层是会话限制，每 5 小时重置一次。Max 20x 的单轮额度是 Pro 的 20 倍，这是「20x」三个字的直接含义。

第二层是每周限制，跨所有模型生效。它的重置时间固定绑定在账户上——每周同一个时点恢复，跟你什么时候开始用、什么时候订阅都无关，每轮周期都能拿到完整的每周额度。你可以在 Settings > Usage 里查看下一次重置时间。

另外，官方文档还提到 Max 套餐单独设有一个 Fable 的每周限额。同时 Anthropic 保留了为管理容量而增设其他上限的权利，比如每周、每月封顶，或对特定模型和功能的用量做限制。白纸黑字写着的规则，用之前心里有数比较好。

具体能发多少条消息？官方没有公布精确数字。第三方指南给出的估算是：Pro 大约每 5 小时 45 条 Opus 或 225 条 Sonnet；Max 5x 大约 225 条 Opus 或 1125 条 Sonnet；Max 20x 大约 900 条 Opus 或 4500 条 Sonnet。这些只能当量级参考，实际消耗跟模型选择、上下文长度、是否开扩展思考都有关系。

### 额度用完了怎么办

两条路。

一是等重置。5 小时的会话额度恢复得很快，很多情况下歇一会儿就够用了。

二是开启 Usage credits（用量点数）。开通之后，超出套餐额度的请求会自动切到按量计费，按标准 API 费率从点数里扣，工作不中断。界面上的提示会从「即将到达限额」变成「正在使用点数」。几个要点：

1. 在设置里找到 Usage credits 区域，点 Enable 开通
2. 绑定支付方式，配置消费偏好
3. 设置月度消费上限控制成本，也可以选不设上限
4. 预充值覆盖超出套餐的部分，或开启余额不足时自动充值
5. 随时可以关闭，关掉后只保留套餐自带额度

注意两点：用量点数和订阅费分开扣款，属于额外支出；它和套餐附带的每月 API credits 是两回事，不能互相抵充。

还有一个地区性细节：自 2026 年 9 月 10 日起，日本等部分地区的用量点数购买后 6 个月过期，过期前 7 天会收到邮件提醒。多数地区不设有效期。

官方还提供 limit reset 这类一次性重置，可以把 5 小时额度或每周额度直接拉回满格，重度用户值得留意。
